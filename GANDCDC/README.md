# 基于 GaN 的高功率密度同步 Buck 降压电源模块（300W）

> **输入 30–60V ｜ 输出 32V·10A（峰值 300W）｜ 开关频率 ≈600kHz ｜ 4 层板 66×43mm**
> 方案：TI **LM5148**（峰值电流模式控制器）+ 英诺赛科 **ISG3202LA**（100V GaN 半桥合封）

---

## 一、项目简介

本项目是一块非隔离同步降压（Buck）电源模块，采用"**通用电流模式控制器 + GaN 半桥合封功率级**"的架构：

- 控制器负责**稳压、限流、软启动、时序**；
- GaN 半桥合封器件负责**真正的高频大电流开关**（自带驱动、自举与保护）。

板级指标：输入 30–60V，输出 32V（由 FB 分压设定），最大 10A / 300W（峰值），开关频率约 596kHz，四层板尺寸 66 × 43mm。

## 四、设计要点（本项目最关键的三件事）

### 1）驱动电平适配：把控制器的驱动"降级"为 5V 逻辑信号

LM5148 原本驱动硅 MOSFET，其栅极驱动电平可达 7V 以上；而 ISG3202LA 的 PWM 输入**绝对最大只有 6V、推荐 5.5V**。解决办法：

- 把 U2 的 **SW(14) 脚经 R13(0Ω) 接地** → 高边驱动不再是"浮动"的，HO 变成**地参考**信号；
- **不装 CBOOT 自举电容** → CBOOT 由内部二极管从 VCC 充到约 4.2V，HO 高电平维持在 5V 以内。

这样 HO/LO 就成了两路 **0–5V 地参考逻辑 PWM**，可直接送进 GaN 的 PWMH/PWML。代价是放弃了 LM5148 的自适应死区真实反馈、PFM 二极管仿真与 PGOOD。

### 2）峰值电流模式双环控制

```
外环（慢）：VOUT → R1/R2 分压 → FB(6) 与 0.8V 基准比较 → 误差放大器 → EXTCOMP 控制电压 COMP
内环（快）：COMP 作为峰值电流门槛 ← 与 R30 采样的电感电流斜波比较 → 决定每周期上管关断时刻
```

- 输出设定：`Vout = 0.8V × (1 + R_top/R_bot) = 0.8 × (1 + 39K/1K) = 32V`
- 逐周期限流：`60mV / 5mΩ = 12A`
- 斜率补偿匹配电感：`L ≈ Vout×Rs/(24×Fsw) ≈ 11.2µH`（实选 10µH）
- 补偿网络：EXTCOMP 上 R4(4.7K) + C1(4.7nF) 串联到地，并联 C2(100pF)（II 型补偿）
- 前馈加速：R3(1.8K) + C8(1.5nF) 跨在上分压两端

### 3）四层板与热设计

- 叠层：**Top（功率+控制）/ Inner1（整片 GND）/ Inner2（VIN 条 + VOUT 条 + GND）/ Bottom（散热）**
- 输入电容 8 颗 4.7µF **对称贴在 GaN 芯片正上/正下方**，最小化输入换流回路（高 di/dt 环路）
- SW 铜皮限制在"芯片→电感"之间，面积尽量小（高 dv/dt 节点）
- 电流采样走 **开尔文 + 差分滤波**（R14/R15 10Ω + C3 10pF），检测线走内层绕开功率区
- U5 焊盘内 **27 个散热过孔**（PGND 12 / VIN 9 / SW 6），配合底部铜皮与外加散热片
- 全板 **588 个过孔**：GND 411、VIN 107、VOUT 46、SW 22、R30 2

## 六、相对原开源方案的改动

原始设计来自立创开源硬件平台（见"致谢"），本版本在其基础上完成：

1. **功率级器件替换**：ISG3201 → **ISG3202LA**（逐脚核对引脚/封装/驱动电平兼容，更新 BOM 与立创编号 C41417827）；
2. **修复底层 SW 铜皮网络名错误**（旧位号遗留网络 → 重新指定为 SW 网络）；
3. **PFM/SYNC(18) 接地**，明确工作于 FPWM（因 SW 已接地，无法做零-cross 检测）；
4. **新增 45 个 GND 缝合过孔**，改善地平面 stitching；
5. **丝印警示更新**（改为"输入带电 / 勿反接"）；
6. **BOM 规范化**：补齐立创编号、标注不贴件、核对电容耐压与二极管型号。

详见 `CHANGELOG.md` 与 `ERRATA.md`。

## 八、复刻步骤

1. **打样**：用 Gerber 下单，4 层 / 1.6mm / 外层 2oz / 沉金 ENIG；
2. **备料**：按 `BOM_normalized.csv` 下单，注意 **ISG3202LA（C41417827）需单独确认货源**；
3. **焊接**：重点核对**极性件**——4 颗贴片铝电解（色带=负极）、D1（色带=阴极），以及三颗芯片的 1 脚方向；
4. **空载上电**（推荐分三级）：
   - 第 1 级：只焊 U3 及外围 → 测 **+5V = 5.0V ±2%**；
   - 第 2 级：装 U2（不装 U5）→ 测 VCC/VDDA ≈5V、LO 有 596kHz 方波、**HO 高电平 ≤5.5V** ⭐；
   - 第 3 级：装 U5 → 测 **VOUT = 32V**、**FB = 0.8V**、SW 斩波正常；
5. **带载验证**：按 `TEST_PLAN.md` 逐项测效率、纹波、动态响应、温升与限流行为。

> ⚠️ 输入电源建议限流 0.3–0.5A 起步；**HO 高电平 ≤5.5V 是本方案的生死线**，超标会直接损坏 GaN。
