# 测试方案与记录表 — GaN 同步 Buck 降压模块

> 目标：验证输出电压、调整率、效率、纹波、动态响应、限流、温升与驱动电平。
> 使用说明：复制下面的"记录表"小节，实测后逐项填入；每一项都记录**测试条件**（输入电压、负载、温度、带宽限制、探头类型），否则数据不可比。

## 三、逐项步骤

### 3.1 上电时序与辅助电源（分三级，推荐）

**第 1 级（只焊 U3 及外围 L3、D1、C29–C34、R16–R20）**
1. 输入设 36V，**限流 0.3–0.5A**；
2. 测 C30/C34 上的 +5V → 应为 **5.0V ±2%**；若偏离，检查 R16/R18；
3. 若电压明显过低（如 4.0V 以下）或限流触发，断电查找短路。

**第 2 级（再装 U2，不装 U5）**
1. 上电，测 U2 的 VCC(9)、VDDA(8) ≈ 5V；
2. 测 EN(19) 电压 >1V；
3. 示波器测 **LO（0–5V，596kHz 方波）**；
4. 示波器测 **HO 相对 GND 的高电平 → 必须 ≤5.5V** ⭐（此时 U5 未装，安全）。

**第 3 级（装 U5）**
1. 空载上电，观察输入电流：应先涌流后快速回落到几十 mA；
2. 依次测：+5V → U5 VCC(29) → LO → HO → SW → VOUT(32V) → FB(0.795–0.808V)；
3. 测 U5/U3/L3 温度（应仅微温）。

### 3.2 输出调整率

1. 万用表接**板子输出焊盘**（不要接在电源/负载接线柱上）；
2. 空载记录 Vout，然后 10A 载记录 Vout；
3. `负载调整率 = (V空载 − V满载) / V额定 × 100%`，目标 ≤1%。

### 3.3 效率（四表法）

1. 输入电压分别设 36V / 48V / 60V（三组）；
2. 每组负载从 0.5A 起，按 1A 步进到 10A；
3. 每点**等温度稳定**（30s–2min）后记录 Vin、Iin、Vout、Iout；
4. `η = (Vout × Iout) / (Vin × Iin) × 100%`；
5. 电压取样点必须在板子焊盘上（避开线缆压降）。

### 3.4 纹波

1. 探头换**弹簧地针**，示波器设 **AC 耦合 + 20MHz 带宽限制**；
2. 探测点选**离输出电容最近的 VOUT/GND 焊盘**；
3. 分别在 1A / 5A / 10A 下读峰峰值 Vpp；
4. `纹波% = Vpp / Vout × 100%`；同时记录是否包含开关尖峰。

### 3.5 动态响应

1. 电子负载设动态模式：1A ↔ 5A（或 2A ↔ 10A），斜率 1A/µs，频率 1kHz；
2. 示波器 AC 耦合测**负载端焊盘**上的 Vout；
3. 记录最大跌落 / 过冲：`偏差% = ΔV / 32V × 100%`；
4. 记录恢复时间（回到 ±1% 所需时间）。

### 3.6 限流与保护

1. 电子负载 CC 模式，从 8A 逐级加到 13A（每级停留数秒）；
2. 观察输出在 **12A 附近**开始被限制（电压下降、电流不再跟随）；
3. 继续超限 → 应进入 hiccup（输出周期性掉压重启）；
4. 记录实际限流点（可用电流探头看峰值）。

### 3.7 温升

1. 额定条件（48V → 32V / 5A，再试 10A）；
2. 热电偶贴 U5 顶面（或本体侧面）、电感 U4、U3、采样电阻 R30；
3. 每 5 分钟记录一次，直到温度稳定（变化 <1°C/5min）；
4. 分别记录"无风冷"与"散热片 + 风冷"两种状态。

## 五、安全与注意事项

1. **输入限流 0.3–0.5A 起步**，确认正常后再逐步放开；
2. **断电后必须给输出电容放电**（32V 残压会电手），用 1kΩ/2W 电阻短接输出；
3. 手背/手指不要长时间触碰 U5 与电感（10A 时温度可超 100°C）；
4. 测纹波**必须用弹簧地针**，长鳄鱼夹地线会测出假尖峰；
5. 首次上电建议有人在场、手放在电源开关上；
6. 测限流时**不要直接短路输出**（首版用电子负载验证行为即可）。
