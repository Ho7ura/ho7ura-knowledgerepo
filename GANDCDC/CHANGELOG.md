## v1.1 — 器件替换 + 设计复核 + 打样优化（2026-09 ~ 2026-10）

### 1. 功率级器件替换
- **ISG3201 → ISG3202LA**（立创 `C41417827`，LGA-25 5×6.5mm）
- 逐脚核对两颗器件的引脚定义：完全一致（1 LGP / 2 LG / 3-4,21-22 VIN / 5-7,18-20,30 PGND / 8-17 SW / 23 HG / 24 HGP / 25 BST / 26 SW / 27 PWMH / 28 PWML / 29 VCC）
- 已核对立创库该封装的焊盘覆盖 1–30 全部引脚（10 个独立焊盘 + SW 梳齿 10 齿 + PGND 6 齿 + VIN 4 齿 = 30 个铜盘）
- 收益：3202LA 底部热阻 4.1°C/W（3201 为 7.7）、保护更全（VCC OVLO / BST UVLO / OTP）、开关更快（14ns vs 17ns）

### 2. 原理图与网络复核
- 确认本方案的"地参考驱动"结构：**U2 SW(14) 经 R13(0Ω) 接地 + CBOOT 位置不装电容** → HO 输出 0–5V 地参考逻辑电平（满足 GaN PWMH/PWML 的 5.5V 上限）
- 确认 **PFM/SYNC(18) 接地**（FPWM 模式）——因 SW 已接地，芯片无法做零-cross 检测，PFM 不可用，因此接地是**必要且正确**的选择
- 核对 CNFG(3) = R5(40K)：判定为"主控 + 扩频开 + 单相"；该配置**上电锁存**，更改需完全断电
- 核对 FB 分压（R10 0Ω + R1 39K / R2 1K → 32V）、前馈（R3 1.8K + C8 1.5nF）、补偿（R4 4.7K + C1 4.7nF + C2 100pF）
- 核对电流采样链路：R30 5mΩ → R14/R15 10Ω + C3 10pF 差分滤波 → ISNS+(20)/VOUT(21)，采用开尔文接法

### 3. PCB 修复与优化
- **修复底层 SW 铜皮的网络名错误**：旧位号遗留网络（`U1_11`）→ 重新指定为 SW 网络（`U4_1`），消除悬空铜皮
- **新增 45 个 GND 缝合过孔**（总过孔数 543 → **588**；GND 411 / VIN 107 / VOUT 46 / SW 22 / R30 2）
- 丝印警示文字更新：删除"强电！/ 禁止触碰！/ 后果自负！！！"，改为 **"输入带电 / 勿反接"**

### 4. BOM 规范化（`BOM_normalized.csv`）
- 补齐主要器件的立创编号与参考价格（U5 `C41417827`、U2 `C7470701`、U3 `C544837`、D1 `C698869`、L3 `C167206`、U4 `C22388353`、电解 `C2836438`）
- 增加 **"是否贴装"** 与 **"备注"** 两列（极性要求、耐压要求、饱和电流要求、关键器件不可替代等）
- 记录待确认项（见 `ERRATA.md`）：47µF 与 22µF 共用同一料号、D1 型号不统一、通用阻容缺立创编号、U4 厂商字段为空

### 5. 新增文档
- `DESIGN_CALC.md`：设计计算书（输出设定、占空比与压差、电感纹波、限流点、斜率补偿匹配、LC 衰减、补偿网络、损耗拆解、热阻路径、时序门槛）
- `TEST_PLAN.md`：测试方案与记录表模板（上电时序 / 调整率 / 效率 / 纹波 / 动态 / 限流 / 温升）
- `ERRATA.md`：踩坑清单与生产注意事项
