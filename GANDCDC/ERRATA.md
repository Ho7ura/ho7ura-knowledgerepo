# 踩坑清单与注意事项

> 这份文档记录本项目在**设计复核、器件采购、打样与上电调试**中容易出问题的点。
> 其中 A 节是"不改就出问题"的硬性要求，B/C/D 节是实践中最容易翻车的地方。

---

## A. 原理与设计（硬性要求，务必核对）

### A1. U2 SW(14) 必须经 R13(0Ω) 接地，CBOOT 位置不装电容 ⭐
ISG3202LA 的 PWMH/PWML 是**以 PGND 为参考**的逻辑输入，绝对最大 6V（推荐 ≤5.5V）。
若 U2 的 SW 接真实开关节點（0–60V），其 HO 的高电平将是 `SW + 5V`（最高约 65V），**会瞬间损坏 GaN**。
本方案通过"SW 接地 + 不装自举电容"把 HO 变成 **0–5V 地参考信号**，这是整套设计成立的前提。

> **上电首测必做**：示波器测 HO（=U5 的 PWMH）相对 GND 的高电平，必须 **≤5.5V**。

### A2. EXTCOMP 的补偿 RC 另一端必须接地
LM5148 的 EXTCOMP 是跨导误差放大器输出。补偿网络（R4 + C1）必须从 EXTCOMP **接到 AGND/GND**，否则环路开环、芯片工作异常。
（这是原始开源方案作者明确指出的原理图错误。）

### A3. PFM/SYNC(18) 应接 GND（FPWM），不要接 VDDA
二极管仿真（PFM/轻载降频）依赖**检测 SW 过零点**判断反向电流；本方案 SW 已接地，无法判断 → PFM 不可用。
接 GND 明确选择 **FPWM（轻载仍连续开关）**，波形固定、便于测量。
（若悬空则电平未定义；若接 VDDA 则期望进入一个无法正常工作的模式。）

### A4. CNFG(3) 的配置是"上电锁存"的
芯片在 VCC 高于约 3.3V 时读取一次 CNFG 电阻并锁定；**要改配置必须完全断电（VCC 掉到 3.3V 以下）再上电**，运行中改电阻无效。
当前 R5 = 40K → 判定为"主控 + 扩频开 + 单相"。

### A5. VCCX(16) 不用时应接 PGND（当前悬空，建议改）
手册原文："Tie VCCX to PGND if it is unused."
悬空时若引脚电压漂到 4.3V 以上，芯片会误判"有外部偏置"并**关闭内部 VCC 稳压器**，而外部又没有提供 5V → VCC 掉电、芯片停工。

### A6. 输出 32V 需要输入 ≥35V
`D = Vout/Vin`，受最小关断时间 90ns 限制，最大占空比约 **94.6%** → 输入最低约 33.8V（理论上），考虑导通压降建议 **≥35V**。
输入 30–35V 时电路进入压差/跟随状态，输出会掉到约 `Vin − 1~2V`。**"输入 30–60V"不等于"全程能出 32V"**。

### A7. 上电门槛存在空档（缓慢升压时才明显）
U2 的 EN 门槛约 **11V**，U3（辅助 5V）的 EN 门槛约 **13V** → 在 11–13V 区间内，控制器已开始发 PWM，但 GaN 还没有 VCC。
阶跃上电（直接给 36–48V）时两个门槛几乎同时越过，无影响；**手动缓慢升压**会看到输出突然上冲。
如需规范化时序：把 **R20 改为 15K**（U3 约 9V 起机）或 **R8 改为 140K**（U2 约 15V 使能）。

### A8. 电感取值与斜率补偿匹配
手册推荐 `L ≈ Vout × Rs / (24 × Fsw)` ≈ **11.2µH**（本设计 32V / 5mΩ / 0.596MHz），实选 **10µH** 合理。
占空比 > 50% 时必须有斜率补偿，否则会出现次谐波振荡——这项由芯片内部提供，**不要随意把电感改得远小于 10µH**。

## B. 器件与采购

### B1. ISG3202LA 的货源与包装
- 立创编号 `C41417827`，单价约 ¥30；**编带 2500 只/盘、MSL3**，散买走商城零售；
- 拆袋后按 MSL3 要求处理（受潮需烘烤），不要长时间裸放；
- 替换前务必确认引脚定义（与 ISG3201 逐脚一致）。

### B2. ⚠️ 电解电容的型号与值不一致
BOM 中 C27/C28/C37 的**值为 47µF，但料号 `RVT22UF50V67RV0028` 是 22µF/50V**。
→ 实际会装成 22µF：输出总容量从"3×47µF"变成"3×22µF"，影响有效容量、纹波与环路。
**处理**：要么把值改为 22µF（并在设计计算中按 66µF 计），要么换用真正的 47µF 料号。

### B3. ⚠️ L3（33µH）被商城配单误配成 2.2µH
辅助电源电感 L3 设计值 **33µH**（`C167206`），但商城"BOM 配单"在缺货时可能按"封装相似"推荐，给出 **2.2µH**（差 15 倍）。
后果：纹波电流从约 0.27A 涨到约 4A，启动时电流冲到限流点，小体积电感的饱和电流可能不足 → 饱和、失控。
**处理**：核对型号；若必须用 2.2µH，务必确认 **饱和电流 ≥3A**，并接受纹波与效率变差。

### B4. ⚠️ D1 型号不统一
BOM 写 `SS510A`（100V/5A 肖特基，`C698869`），但仓库里同时存在 **ES1x 系列**（1A 超快恢复）的手册。
→ 必须确认实际使用哪颗：
- 若用 ES1x：**耐压必须 ≥100V**（ES1A/50V 不够！），电流能力 1A（本板辅助电源负载仅几十 mA，够用）；
- 两者 A/VF 不同，会影响辅助电源效率。

### B5. 通用阻容缺少立创编号
BOM 中多数 R0603/C0603 行的 Supplier Part 为空 → 无法一键下单、价格也算不全。
建议补齐（电阻选 1% 精度；C1210 4.7µF 建议 100V 耐压以保证 60V 输入余量）。

### B6. U4（10µH）的厂商字段为 null
补齐实际采购品牌的型号，便于替换与追溯。该电感为 Pulse PA2247 系列同尺寸（16.5×15.5mm），额定 24A / 饱和 26A / DCR 7.1mΩ。

## C. PCB 与生产

### C1. 极性器件（贴片前必核）
| 器件 | 极性规则 | 方向 |
| --- | --- | --- |
| C27、C28、C37、C29（贴片铝电解） | **色带/黑边 = 负极** | 输出三颗"+"朝 VOUT；输入那颗"+"朝 VIN |
| D1（二极管） | **竖线/色带 = 阴极（K）** | 阴极朝 U3 的 SW 节点侧（丝印竖线一侧），阳极接 GND |
| U2 / U3 / U5 | 有方向（1 脚位置） | 按丝印/封装 1 脚标记 |

> 陶瓷电容（C0603/C1206/C1210）、电阻、电感(U4/L3) **均无极性**，可任意旋转。

### C2. 焊盘内过孔建议做"树脂塞孔 + 电镀填平"
本设计有 **47 个过孔直接位于焊盘内**（U5 27 个、U2 EP 6 个、若干电容）。若孔口是通的，回流焊时焊料会被吸走 → 焊点空洞、虚焊。
下单时优先勾选塞孔/填平；若厂家不支持，至少提前告知代工厂。

### C3. 4 层 / 2oz 外层的工艺核对
- 叠层建议：Top（功率+控制）/ Inner1（整片 GND）/ Inner2（VIN 条 + VOUT 条 + GND）/ Bottom（散热）；
- 板厚 1.6mm、外层 2oz、沉金 ENIG；
- **本设计最小间距 0.152mm（6mil）**，而 2oz 外层对最小线宽/间距要求更严（常见 0.15–0.2mm）→ 下单前用厂家的工艺能力页核对，必要时改回 1oz 或放大间距。

### C4. 散热片与绝缘
散热片为 66×43mm CNC 铝件：**与 PCB 铜皮之间必须加导热绝缘垫**（否则可能短路 SW 等带电铜皮）；1 元 CNC 不支持攻丝，需自行 **M3×0.5** 攻丝。

### C5. 底层 4 处阻焊开窗
芯片下方有 4 处矩形阻焊开窗（原设计用于散热/堆锡）。保留即可，但焊接后注意清洁，避免锡渣造成短路。

## D. 上电与调试

### D1. 空载上电的推荐顺序
1. 输入设 36V、**限流 0.3–0.5A**（太小会被输入电容涌流误触发限流）；
2. **分三级**：只焊 U3 → 测 +5V；装 U2（不装 U5）→ 测 HO 电平；装 U5 → 测输出；
3. 观察输入电流：应为"涌流后快速回落到几十毫安"；若稳在限流值 → 立即断电查短路。

### D2. 空载时的正常现象（不要误判）
- **空载仍连续开关、频率固定** → 正常（FPWM 模式不会跳周期）；
- **空载输入电流几十 mA** → 正常（600kHz 开关损耗 + 辅助电源损耗）；
- **输出电压略高于 32V** → 正常（空载无负载压降）。

### D3. 异常判据
| 现象 | 含义 |
| --- | --- |
| 输入电流稳在限流值、输入电压被拉低 | 短路或器件损坏 |
| 输出远高于 32V | FB 分压开路 → **立即断电** |
| U5 迅速发烫 | 上下管直通或驱动异常 |
| 输出打嗝、频率乱跳 | 自举/限流/环路问题 |

### D4. 断电后要给输出电容放电
输出电容 32V 残压会电手，用 1kΩ/2W 电阻短接输出即可。

## E. 测量注意（决定数据可信度）

| 项目 | 正确做法 | 常见错误 |
| --- | --- | --- |
| 纹波 | **弹簧地针**、AC 耦合、**20MHz 带宽限制**、就近输出电容焊盘 | 用长鳄鱼夹地线 → 全是耦合尖峰 |
| 效率 | 电压取**板子焊盘**、逐点等热平衡、四表法或功率分析仪 | 在电源/负载接线柱取压 → 线缆压降算进损耗 |
| 频率 | 读**平均值/抖动范围** | 只读瞬时值（展频 ±7% 会让读数乱跳） |
| 限流 | 电子负载逐级加流看行为、可配电流探头 | 直接短路测试（首版危险的） |
| 动态 | 探头放在**负载端焊盘** | 接在负载接线柱 → 线缆电感放大偏差 |

## F. 已知不足（可作为后续改进方向）

1. 底层 SW 铜皮与顶层重复，dv/dt 耦合面积偏大 → 可缩小或去掉底层 SW 铜皮；
2. 新增的 45 个 GND 缝合过孔位于电感北侧，对芯片散热帮助有限 → 建议移到 U5 焊盘周边与输入/输出电容地焊盘旁；
3. VCCX 悬空（见 A5）；
4. 采样电阻为 R2512，手册推荐 0508 宽体封装（寄生电感更低）；
5. U3 的 0.1µF 输入电容距 U3 VIN 约 5mm，可再靠近；
6. 输出端无过压/短路/反接保护，仅为芯片级保护（逐周期限流 + hiccup）；
7. 尚无实测数据（效率曲线、温升、纹波、动态响应）——待打样后按 `TEST_PLAN.md` 回填。
