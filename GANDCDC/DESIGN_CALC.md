# 设计计算书 — GaN 同步 Buck 降压模块（32V / 10A）

> 说明：本文所有公式与数值均可由 BOM 中的实际取值复算；标注"估算"的为工程估算值，标注"实测"的来自原始开源方案的公开数据。
> 计算条件：Vin = 48V、Vout = 32V、Iout = 10A、fsw ≈ 596kHz（RT = 36K）、L = 10µH、Rs = 5mΩ、Cout ≈ 90–180µF。

---

## 1. 输出电压设定（电压外环）

LM5148 内部基准 `VREF = 0.8V`（795–808mV），输出由 FB 分压决定：

```
Vout = VREF × (1 + R_top / R_bot)
     = 0.8V × (1 + (R10 + R1) / R2)
     = 0.8V × (1 + (0Ω + 39K) / 1K)
     = 0.8V × 40
     = 32.0V
```

**容差**：基准 ±0.8% + 电阻 ±1% → 约 **31.5–32.5V**。
改压公式：`R_top = R_bot × (Vout / 0.8V − 1)`（保持 R2 = 1K 时，R_top = 1.25×Vout − 1 [kΩ]）。

---

## 2. 占空比与输入电压范围

```
D = Vout / Vin
```

| Vin | 占空比 D | 上管导通时间（T = 1.678µs） |
| --- | --- | --- |
| 35V | 0.914 | 1.53µs |
| 48V | 0.667 | 1.12µs |
| 60V | 0.533 | 0.89µs |

**最大占空比限制**：手册最小关断时间 `tOFF(min) = 90ns`

```
Dmax = (T − tOFF(min)) / T = (1.678µs − 0.09µs) / 1.678µs ≈ 94.6%
→ Vin(min) ≈ Vout / Dmax ≈ 33.8V（理论），考虑导通压降建议 ≥35V
```

**结论**：标称"输入 30–60V"在输出 32V 时无法全范围稳压；实际可用输入 ≈ **35–60V**（30–35V 之间会进入压差/跟随状态，输出 ≈ Vin − 1~2V）。

---

## 3. 电感纹波与峰值电流

```
ΔIL = Vout × (1 − D) / (L × fsw)
```

| Vin | D | ΔIL（L = 10µH） | 峰值电流（Iout = 10A） |
| --- | --- | --- | --- |
| 35V | 0.914 | 0.46A | 10.2A |
| 48V | 0.667 | **1.79A** | **10.9A** |
| 60V | 0.533 | 2.51A | 11.3A |

峰值电流均低于 12A 限流点，**但 60V 输入时余量只剩约 0.7A**——这也是"满载 10A 需谨慎"的原因之一。

---

## 4. 逐周期限流点（电流内环）

```
I_limit = VCS-TH / Rs = 60mV / 5mΩ = 12A
```

**传播延迟导致的峰值超调**（手册给出 CS→输出延迟 ≈ 40ns）：

```
ΔI_over = (Vin − Vout) / L × t_delay
        = (48V − 0V) / 10µH × 40ns ≈ 0.19A（短路最坏情况）
        = (48V − 32V) / 10µH × 40ns ≈ 0.06A（正常工况）
```

→ 实际峰值限流约 **12.1–12.2A**。
**设计校验**：手册建议 `Rs = VCS-TH / (1.25 × IL_peak) = 60mV / (1.25 × 10.9A) ≈ 4.4–5.0mΩ` → 选 **5mΩ** 符合推荐。

---

## 5. 斜率补偿与电感匹配

峰值电流模式在 **D > 50%** 时会出现次谐波振荡，需要内部斜率补偿；手册给出电感选取公式（使补偿量 ≈ 1× 电感下降斜率）：

```
L(µH) ≈ Vout(V) × Rs(mΩ) / (24 × Fsw(MHz))
      ≈ 32 × 5 / (24 × 0.596)
      ≈ 11.2µH
```

→ **实选 10µH，与推荐值一致**（略小 → 纹波略大、补偿余量更足）。

---

## 6. 输出 LC 滤波与纹波

**截止频率**（L = 10µH）：

| 有效输出容量 | fc | 对 596kHz 的二阶衰减 |
| --- | --- | --- |
| 180µF（标称合计） | 3.75kHz | 88dB |
| 120µF | 4.6kHz | 85dB |
| 90µF | 5.3kHz | 82dB |
| 80µF | 5.6kHz | 81dB |

> ⚠️ 有效容量要打折：陶瓷电容（4.7µF/1210）在 32V 偏压下通常只剩标称的 50–70%；三颗"47µF"按 BOM 料号实为 22µF。
> 保守表述：**LC 低通截止约 4–5kHz，对开关频率衰减 80dB 以上**。

**输出纹波估算**（48V→32V，10A）：

```
容性纹波：ΔV = ΔIL / (8 × fsw × Cout) = 1.79A / (8 × 596kHz × 90µF) ≈ 4.2mV（≈0.013%）
ESR 贡献：ΔV ≈ ΔIL × ESR ≈ 1.79A × 2mΩ ≈ 3.6mV
```

→ **理论三角纹波只有几 mV**；实测 0.2%（约 64mV）主要由**开关尖峰与测量耦合**贡献，因此测纹波必须用弹簧地针 + 20MHz 带宽限制。

---

## 7. 环路补偿网络（II 型，估算）

EXTCOMP 上：`R4 = 4.7K`（串联）→ `C1 = 4.7nF`（到地），并联 `C2 = 100pF`。

| 项目 | 计算 | 结果 |
| --- | --- | --- |
| 零点（R4 与 C1） | `1 / (2π × R4 × C1)` | ≈ **7.2kHz** |
| 高频极点（R4 与 C2） | `1 / (2π × R4 × C2)` | ≈ **54kHz** |
| 积分作用 | C1 提供 | 保证直流精度 |

**FB 前馈网络** `R3 = 1.8K + C8 = 1.5nF` 跨在上分压两端，等效零点约：

```
fz_ff = 1 / (2π × R3 × C8) ≈ 59kHz
```

作用是为输出突变提供一条"绕过 R_top 的快速通路"，提升相位裕度与瞬态响应。

> 以上为估算值；精确补偿应以环路测量（或 TI 的 LM5148 快速设计工具）为准。

## 8. 损耗拆解与效率（48V → 32V，10A，估算）

| 损耗项 | 计算 | 估算值 |
| --- | --- | --- |
| 上管导通 | `(10×√0.667)² × 2.4mΩ` | 0.16W |
| 下管导通 | `(10×√0.333)² × 2.4mΩ` | 0.08W |
| 开关损耗（边沿约 10ns） | `0.5 × Vin × Iout × (tr+tf) × fsw` | ≈ 1.4W |
| Coss 损耗 | `Qoss × Vin × fsw`（同步整流部分回收） | ≈ 0.5–1.4W |
| **死区反向导通**（GaN 无体二极管） | `Vf × Iout × 2 × tdead × fsw`（Vf≈2.5V, tdead≈40ns） | ≈ 1.2W |
| 栅极驱动 | `Qg × Vgs × fsw × 2`（Qg≈9nC） | 0.05W |
| 电感铜损 | `Iout² × DCR`（DCR ≈ 7.1mΩ） | 0.71W |
| 电感铁损 | 估算 | ≈ 0.3W |
| 采样电阻 | `Iout² × 5mΩ` | 0.50W |
| PCB 铜损等 | 估算 | ≈ 0.3W |
| **合计** | | **≈ 5.6–6.5W** |

→ 估算效率 ≈ `320 / (320 + 6) ≈ 98%`；**原始开源方案公开实测峰值效率 97.6%**（峰值出现在中载），差距主要来自死区损耗、Coss 损耗与布局寄生。

## 9. 热阻路径与温升（估算）

| 路径 | 热阻 | 说明 |
| --- | --- | --- |
| U5 结到壳（底部） | **4.1 °C/W** | 主散热通道（对应焊盘内 27 个过孔） |
| U5 结到壳（顶面） | 14.8 °C/W | 经导热垫 → 铝散热片 |
| PCB 过孔+铜皮 | ≈ 10–20 °C/W | 取决于过孔数量与铜厚（预估） |

**推算**：若 GaN 上损耗约 3W，结到板温升 ≈ 12°C，加上 PCB 热阻（10–20°C/W → 30–60°C）与环境温度 40°C → **芯片温度接近或超过 100°C**，与原作者"10A 时芯片很快超 100°C"的实测一致。

**结论**：**热是持续功率的唯一瓶颈**。无强制风冷时建议长期 ≤5A；10A 必须配散热片 + 风冷，且为瞬态/短时能力。

## 11. 上电时序门槛（本项目需要注意的一点）

| 谁 | 分压 | 起机输入 |
| --- | --- | --- |
| U2（LM5148）EN | R8/R9 = 100K/10K（阈值 1V） | **约 11V** |
| U3（LMR16020）EN | R19/R20 = 100K/10K（阈值约 1.2V） | **约 13V** |

因为 **U2 比 U3 先使能**，在输入从 11V 缓慢升到 13V 的区间内，控制器已经在发 PWM，但功率级（U5）还没有 VCC → 输出为 0；等 U5 一得电，环路已处于最大占空比状态，输出会以限流点为界快速上冲。

**实际使用**（直接给 36–48V 阶跃上电）两个门槛几乎同时越过，看不到这个空档；**只有手动缓慢升压时才会观察到**。

**可选改进**（若要规范化时序）：把 **R20 改为 15K**（U3 约 9V 起机，先于 U2），或把 **R8 改为 140K**（U2 约 15V 才使能）。
