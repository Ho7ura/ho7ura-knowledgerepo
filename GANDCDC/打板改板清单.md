# GANDCDC（GaN DCDC 降压模块）改板清单 —— 打板前逐项过

## 0. 先定三条"生死线"（在 EDA 里核对，动手改之前先确认）

**【必查】0.1 U2（LM5148）的 SW 脚（14 脚）接到哪里？**

- U1 的 PWMH(27)/PWML(28) 是**以 PGND 为参考**的逻辑输入，绝对最大 6V（推荐 ≤5.5V）。
- 如果 U2 的 HO 是一个以功率开关节点 SW 为返回端的高端驱动，它的高电平就是 `SW + 5V`；输入 60V 时 PWMH 会看到约 65V —— 直接损坏，且 LM5148 自身 CBOOT 对 SW 的绝对最大只有 6.5V。
- 作者的原文是：**"禁用此芯片的自举电路，不焊接自举电容，这样高端驱动 PWM 引脚发出的信号电平也会是 5V"**，即 U2 在这里只当"地参考的 5V 逻辑驱动器"用，真正的半桥驱动是 U1 内部完成的。
- 你要确认的是：U2 的 SW(14) 是否按地参考处理、HO(13) 相对 PGND 的高电平是不是 5V。**如果发现 U2 的 SW 接的是功率级 SW 节点，这一条必须改掉，不能直接打板。**

**【必改】0.2 自举电容：原理图保留，BOM/贴片标"不贴"。**

就是 U2 CBOOT(15)–SW(14) 之间那颗 0.1µF。手册原话是"推荐 0.1µF 接在 CBOOT 与 SW 之间"，本设计**反其道而行**，正是为了压住 PWMH 的电平。原理图上保留符号、加注释，BOM 标 DNP、贴片单里勾"不贴"，否则工厂一定会给你贴上。

**【必查】0.3 HO(13) → U1 PWMH(27)、LO(11) → U1 PWML(28) 必须直连。**

中间不能有上拉、分压、电平转换、串阻（除 0R 跳线外）。U1 侧 PWMH/PWML 内部各有 200kΩ 下拉，不需要外部再加下拉电阻。

## 1. 原理图必改项

### 1.1【必改】EXTCOMP 补偿网络的接地

- U2 的 **EXTCOMP(5 脚)** 是跨导误差放大器输出，手册明确："If used, connect the compensation network from EXTCOMP to **AGND**"。
- 作者勘误原文："原理图存在有错误，EXTCOMP 引脚接的 RC 另一端没有接地，需要进行接地处理，否则芯片会工作异常"。
- 改法：把 EXTCOMP 那组 RC 的公共端接到 **AGND(7 脚)**（接模拟地，不要接 PGND，也不要在功率地上随便就近打孔）。
- 同步检查：这组 RC 的接地过孔在 PCB 上要真的存在（原理图改了、PCB 没加过孔是最常见的漏网）。

### 1.2【必改】U1 换料：ISG3201 → ISG3202LA

| 项 | 说明 |
| --- | --- |
| 封装 | 都是 **LGA5x6.5-30L**，引脚定义逐条相同（1 LGP、2 LG、3-4/21-22 VIN、5-7/18-20/30 PGND、8-17 SW、23 HG、24 HGP、25 BST、26 SW、27 PWMH、28 PWML、29 VCC） |
| EDA 操作 | 符号/封装不用重画；把器件型号、立创编号改成 **C41417827**，方便直接 BOM 配单 |
| 别做多余的事 | **不要**再外并自举电容（两颗都是内部集成）；**不要**给 VCC(29) 加大电容（内部已集成 2×0.1µF，外部 0.1µF 可选） |
| 可选核对 | 在 EDA 里把 ISG3202LA 的焊盘图叠到原封装上，确认引脚序号一一对应后再下单 |

**库里两个 ISG3202LA 器件怎么选（查证结果）**

立创库搜索里会出现两条：

| 器件 | 立创编号 | 封装名 | 厂商 |
| --- | --- | --- | --- |
| ISG3202LA | 空（nul） | 7LGA-30_L6.5-W5.0-P0.85-TL | 空 |
| ISG3202LA | **C41417827** | 7LGA-**25**_L6.5-W5.0-P0.85-TL | Innoscience(英诺赛科) |

- **优先选带 C41417827 的那条**：立创商城配单、SMT 贴片都靠立创编号自动匹配；没有 C 号的那条在 BOM/SMT 里会变成"未匹配"。
- 那条的封装虽然叫 `LGA-25`，但**实测焊盘覆盖 1–30 全部引脚**：10 个独立焊盘（1、2、23、24、25、26、27、28、29、30）+ SW 梳齿焊盘 10 齿（8–17 脚）+ PGND 梳齿 6 齿（5、6、7、18、19、20）+ VIN 梳齿 4 齿（3、4、21、22）；脚间距 0.85mm，焊盘整体约 4.87×6.26mm，与手册 LGA5×6.5-30L 一致。名字里的 "25" 是立创的命名遗留，不是脚数。
- 它的符号把同网络的多个脚合并成一个引脚（VIN、PGND、SW 各一个），原理图更干净，不影响网表。
- 什么时候选没有 C 号的那条（LGA-30）：你要在原理图上把 30 个脚逐个单独连（例如给 SW 的几个脚分别放测试点），或者你手工买料手工焊、不用商城配单/SMT。选了它，记得手动把 BOM 的供应商编号填成 `C41417827`。
- **最省事的方案**：直接用原工程 U1 的封装（作者的 ISG3201 封装），只把器件型号与供应商编号改成 `ISG3202LA / C41417827` —— 布局、散热过孔阵列、输入电容的对称排布全部不动，风险最低。只有在作者原封装画错/不完整时，才换成库里的封装，换完记得重跑 DRC 并复查芯片底部的散热过孔和输入电容位置。

### 1.3【必查】辅助电源输出电压必须是 5.0V（决定 PWM 电平）

- U2 的 VCC/VCCX 电压基本就是 HO/LO 的高电平，而 U1 的 PWMH/PWML 上限是 5.5V（绝对最大 6V）。
- U3（LMR16020PDDA）是可调输出，输出由分压电阻决定 —— **确认它给到 U2 VCCX(16)/VCC(9) 的是 5.0V**，不能是 5.6V、6V 这类"差不多"的值。
- 如果原设计把 5V 接到 VCCX(16)，则 LM5148 内部 VCC 稳压器被自动关闭，全部驱动电流由外部 5V 提供 —— 这正是作者测到"PWM 信号 5V"的来源，保持这个做法。

### 1.4【必改】FB 分压按你要的输出电压重算

- LM5148 的 FB 基准 **VREF = 0.8V**（795–808mV），公式：`Vout = 0.8 × (1 + R_top / R_bot)`。
- 手册建议下分压电阻 **RFB2 取 10kΩ–20kΩ**；作者的设计是可调输出（走 EXTCOMP 外部补偿），所以必须用分压，不能用"FB 直接接 VDDA"的 3.3V/5V/12V 固定档。
- 参考计算：要 12V → R_bot=10kΩ、R_top=140kΩ；要 5V → R_bot=10kΩ、R_top=52.3kΩ；要 24V → R_bot=10kΩ、R_top=287kΩ（选标准值后回算，误差 <1%）。
- BOM 里 `100K`（R8/R19）、`10K`（R9/R20）、`39K`（R1）、`36K`（R6）、`110K`（R16）、`20K`（R18）这几组数值里就藏着分压和 RT/EN/CNFG 配置，**必须在原理图上按网络确认哪两颗是 FB 分压**（连到 U2 pin6 的那两颗），不要凭数值猜。
- 上分压电阻的上端要从**输出电容之后**取样（Kelvin 取样点），不要从电感上取。

### 1.5【必查】开关频率（RT）与展频（CNFG）—— 作者没做到的那一条可以改

- **RT(4 脚)** 对 AGND 的电阻决定频率（100kHz–2.2MHz，VRT=0.5V）。按手册表格拟合：`fsw ≈ 21472 / RRT[kΩ] kHz`。
  - 600kHz → RRT ≈ 35.7kΩ（BOM 里的 `36K` 很可能是这颗，对应约 596kHz，与作者实测 580kHz 吻合）。
  - 想跑 900kHz → RRT ≈ 23.9kΩ；想跑 350kHz → RRT ≈ 61.4kΩ。
- **CNFG(3 脚)** 对 GND 的电阻同时决定"主/从 + 展频开/关 + 是否双相"，手册 Table 8-2：

| RCNFG | 主/从 | 展频 | 双相 |
| --- | --- | --- | --- |
| **29.9kΩ** | Primary | **OFF** | Disabled |
| 41.2kΩ | Primary | ON | Disabled |
| 54.9kΩ | Primary | OFF | Enabled |
| 71.5kΩ | Primary | ON | Enabled |
| 90.9kΩ | Secondary | — | — |

- 作者原文说"LM5148 芯片有展频模式，暂时无法关闭"。按手册，**把 RCNFG 改成 29.9kΩ 就能关掉展频（保持单相）**。展频关闭后实测频率会更贴近设定值（作者测到的 580kHz vs 设定 600kHz，一部分就是 DRSS 的 ±7% 摆动造成的）。
- 注意：CNFG 电压是在 VCC 超过 3.3V 时锁存的，改完必须完全断电重上电才生效。

### 1.6【必查】EN(19 脚) 的起机门槛

- EN 是"上升阈值 1V + 10µA 滞回电流"的精密输入，靠分压设定最低输入电压。
- 本模块标称最小输入 12V，核对分压是不是按 ~12V 起机（建议留余量：约 11.5V 开、10.5V 关）。如果分压比是按更高电压算的（例如按 36V），12V 输入时根本起不来。

### 1.7【必查】PFM/SYNC(18 脚) 接哪

- 接 **VDDA** = 允许二极管仿真（轻载降频、效率高、纹波大）；
- 接 **AGND** = 强制 PWM（FPWM，轻载连续导通，纹波小、空载效率低）。
- 实验台模块建议 FPWM（波形干净、便于测量）；核对原设计是哪种，并确认和你的使用场景一致。

### 1.8【建议】补上原设计缺的这几样

作者自己写了"输入正负极不能接反，接反可能会损坏模块"、"无输出接口（需要焊接线材进行连接）"，所以建议顺手补：

- 输入防反接：P-MOS（60V 以上耐压）+ 栅极稳压二极管，或者理想二极管控制器。
- 输出端子：2pin 大电流端子/接线柱 + 输出测试点。
- 输出保护：TVS（SMBJ 系列）+ 快熔保险丝；带电机/感性负载再加 RC 吸收。
- 状态指示：U2 的 **PG/SYNCOUT(17 脚)** 是开集输出，可接 LED + 限流电阻做"输出在稳压窗口内"指示（窗口约 92%–110%）。
- 测试点：VIN、VOUT(+/-)、SW、HG、LG、PWMH、PWML 各留焊盘（作者已引出栅极测试点，保留）。

## 3. PCB 改动（按优先级）

1. **【必改】层数**：作者明确"不推荐使用 2 层板"。用 4 层：Top（功率+器件）/ 内层1 完整 GND / 内层2 功率或 GND / Bottom（散热）。4 层还能顺手把底部散热铜皮做大。
2. **【必改】U1 底部散热**：ISG3202LA 的 RθJC(底)=4.1 °C/W（3201 是 7.7），**芯片散热焊盘下打密集过孔阵列**（0.3mm 孔、间距 0.6–0.8mm、覆铜/塞铜），Bottom 面做整片散热铜。这是对作者"10A 时芯片破 100°C"最直接的改善。
3. **【必查】输入电容对称排布**：16×4.7µF（C1210）围绕 U1 的 VIN(3-4、21-22) 与 PGND(5-7、18-20、30) 两侧**对称**放置，距离芯片引脚越近越好，0.1µF 放最内侧；VIN→PGND 的换流回路面积越小越好。
4. **【必查】SW 铜皮**：够载流即可，不要大面积铺开；SW 铜皮不要延伸到散热片下方/芯片边缘以外，减少辐射和耦合。
5. **【必查】功率环路**：VIN 电容 → 芯片 VIN/PGND → SW → 电感 U4 → 输出电容，环路面积最小化；电感到输出电容的走线短而宽。
6. **【必查】采样电阻 R30（5mΩ）**：U2 的 ISNS+(20) 与 VOUT(21) 分别从电阻两端 Kelvin 引出（手册要求"low-current Kelvin connection"），大电流路径与采样线不能共用。
7. **【必查】FB / EXTCOMP**：这两组网络靠近 U2，远离 SW 节点和电感；EXTCOMP 的 RC 接地过孔要有。
8. **【建议】驱动速度调节位**：HGP–HG（U1 pin24–23）、LGP–LG（pin1–2）之间的串联电阻（原 BOM 里是 0R）**预留成可焊 2–5Ω 的 0603 位置**。3202 的开关更快（14ns vs 17ns），作者原板实测振铃明显，这个位置是最省事的调节点。
9. **【建议】辅助电源区**：U3（LMR16020）按手册布局，输入/输出电容就近，反馈走线避开 SW。
10. **【建议】U1 VCC(29) 旁放一颗 0.1µF**（手册说可选，就近放一颗更稳）。
11. **【必查】散热片机械与绝缘**：原设计用嘉立创 1 元 CNC 铝散热片（66×43mm，与 PCB 同尺寸），**不支持攻丝，需要自己 M3×0.5 攻丝**。
    - PCB 上按散热片孔位留 4 个 M3 安装孔，孔周留禁布区；
    - **散热片与 PCB 铜皮之间必须加导热绝缘垫**：一旦铝片压到 SW 或其他带电铜皮，等于把开关节点短路；
    - 丝印标出散热片安装方向与螺丝位置。
12. **【必查】丝印**：输入/输出正负极、`12–60V IN / ≤35V 10A OUT`、`勿反接`、散热片方向、层数版本号。
13. **【建议】大电流路径宽度**：10A 输出在 1oz 外层的温升很可观，功率路径按铺铜处理（等效宽度 ≥4mm）；有条件外层铜厚上 2oz。

## 5. 回板上电顺序（每步都有必须测的点）

1. **只焊 U3 及外围**（不装 U1、U2）：上 12–24V，测 U3 输出 = **5.0V ±2%**。偏高就改分压，别往下走。
2. **装 U2**（不装 U1）：测 U2 的 VCC/VCCX ≈ 5V；测 EN 分压是否在预期输入下起机；测 LO 有 PWM。
3. **测 HO(PWMH) 相对 PGND 的高电平，必须 ≤5.5V**。这是整个设计的生死线；顺便看它的波形是不是随 SW 摆动（若随 SW 摆动，回到第 0.1 条，先解决拓扑问题）。此时还没装 U1，芯片是安全的。
4. **装 U1**，输入先给 12–24V 空载上电：测输出电压是否等于设计值（不等于就查 FB 分压）；示波器看 SW 波形（作者原板在 580kHz/860kHz 都有明显振铃，新板看了再决定要不要动手）。
5. **逐步加载** 1A → 3A → 5A：看效率、输出纹波（作者 280W 时纹波 0.2%）、动态负载阶跃（作者 1.9%）、U1 温升。
6. **装散热片（带绝缘垫）+ 强制风冷**后再做长时间测试。作者结论：无风扇时长期工作在 **5A 以内**；10A 时即使有散热片+风扇，芯片也很快超 100°C。
7. 收尾：确认无风扇/有风扇两档的持续时间限制，并把结论写到实物标签上（**不要**按 300W 连续使用，那是瞬态能力）。
